### FURPS+ Таблица для проекта цифровизации депозитного направления банка «Стандарт»

| Код | Требования                         | Комментарий                                                                                  |
|-----|------------------------------------|----------------------------------------------------------------------------------------------|
| **F** | **Функциональные (Functionality)** |                                                                                              |
| F1  | Клиенты могут подавать заявки на депозиты через сайт и интернет-банк. | Требуется интеграция с кол-центром и АБС. На сайте — сбор данных, в интернет-банке — подтверждение СМС. |
| F2  | Личная идентификация новых клиентов в отделении. | Обязательно по регуляторным нормам. Данные должны синхронизироваться с АБС.                 |
| F3  | Шифрование данных при передаче (TLS для сайта, защищённые API). | Критично для защиты PII-данных (Ф.И.О., номера телефонов).                                  |
| F4  | Интеграция с СМС-шлюзом для уведомлений. |                   |
| F5  | Автоматический расчёт ставок в АБС вместо Excel. | Интеграция кредитного и депозитного модулей через API с контролем доступа.                  |
| **U** | **Удобство использования (Usability)** |                                                                                              |
| U1  | Интерфейсы соответствуют корпоративному стилю (цвета, бренд). | Снижает риск ошибок пользователей и улучшает восприятие.                                    |
| U2  | Время отклика операций — менее 1 секунды. | Требуется кэширование справочных данных (ставки, условия) для ускорения работы.              |
| **R** | **Надёжность (Reliability)**       |                                                                                              |
| R1  | Доступность интернет-банка — 99.9%. | Горизонтальное масштабирование и использование резервного ЦОДа.                             |
| R2  | АБС выдерживает нагрузку от онлайн-заявок. | Вертикальное масштабирование АБС, буферизация запросов через Kafka.                         |
| R3  | Резервное копирование данных в реальном времени. | Обеспечивает восстановление при сбоях в ЦОД.                                                |
| **P** | **Производительность (Performance)** |                                                                                              |
| P1  | Обработка заявок в реальном времени (миллисекундный отклик). | Оптимизация запросов к АБС, кэширование данных.                                              |
| P2  | Масштабируемость интернет-банка (горизонтальное масштабирование). | Переход на микросервисную архитектуру для модуля депозитов.                                 |
| **S** | **Поддерживаемость (Supportability)** |                                                                                              |
| S1  | Использование существующих технологий (MS SQL, Oracle). | Совместимость с текущим стеком, снижение затрат на обучение.                                |
| S2  | Документация для расширения системы. | Чистая архитектура и модульность упростят будущие доработки.                                |
| S3  | Мониторинг нагрузки на АБС и интернет-банк. | Выявление узких мест и планирование масштабирования.                                        |
| **+R** | **+ Ограничения (Restrictions)**   |                                                                                              |
| +R1 | АБС масштабируется только вертикально. | Архитектура базы данных Oracle не поддерживает горизонтальное масштабирование.              |
| +R2 | Интернет-банк работает на монолитной архитектуре. | Переход на микросервисы только для модуля депозитов.                                        |
| +R3 | Текущая версия интернет-банка несовместима с Kafka. | Требуется промежуточный слой (например, REST-API) для интеграции.                           |
| +R4 | Сотрудники кредитного и депозитного отделов не имеют доступа к данным друг друга. | Реализация ролевой модели в АБС для изоляции модулей.                                       |
